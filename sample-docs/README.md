# Sample Documents

These are original documents written specifically for rag-starter. Every file is
released under CC0 (public domain) — you can use, modify, and redistribute them
without restriction.

## What is in here

| File | Description |
|---|---|
| `remote-work-best-practices.md` | Internal company guide covering async communication, meetings, and documentation culture |
| `project-management-fundamentals.md` | Training document on scope, the iron triangle, stakeholder management, and risk registers |
| `intro-to-machine-learning.md` | Beginner explainer covering supervised and unsupervised learning, overfitting, and real-world applications |
| `healthy-eating-guide.md` | Wellness guide on macronutrients, portion control, hydration, and common nutrition myths |
| `berlin-travel-guide.md` | Personal travel blog post with neighbourhood recommendations, food picks, and cultural tips |
| `what-is-rag.md` | Plain-English explanation of Retrieval-Augmented Generation — the technique this project implements |

## Why these topics

The documents cover deliberately diverse subjects — travel, nutrition, technology,
management, work culture, and AI — so you can test cross-document retrieval. When
you ask a question, a good RAG pipeline should pull context only from the relevant
document(s) and ignore the rest.

If you want to test with your own files, see `bring-your-own-docs/`.
